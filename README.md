# MHADB Main board

ESP32-S3 Mhadb line follower main pcb with can interfaces and integrated BMS and 5b buck converter

## IC List

- ESP32-S3-WROOM
- LDL212 (3v3 LDO)
- BQ77905 (3S battery protection)
- TPS56A37 (5v smps)
- SN65HVD (CAN transceiver)
- TMP117 (I2C temperature sensor)
